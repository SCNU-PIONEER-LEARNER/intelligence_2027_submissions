## 1.2 数据类型思考
1、字节是计算机储存数据的基本单位（1字节 = 8位）
2、不同类型的数据的大小不一定相同
3、计算机的“内存”是程序运行时暂存数据的空间
4、程序运行后，操作系统会把需要的内容装进内存，此时删除磁盘上的程序文件，已运行的程序不会立即停止
5、auto不是固定的数据类型（像是让编译器自适识别出右侧的数据类型）
